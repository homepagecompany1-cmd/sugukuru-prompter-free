撮影プロンプター

原稿を読みこんでいます…

入れると：原稿が出る → 声が問いを読む → ピッ → 撮影開始。入れないと：原稿が出る → ピッ → 撮影開始。

  1. スマホを三脚などに立てて、インカメラ（画面側）を顔に向ける
  2. 「ピッ」が鳴ったら、画面の原稿を読む
  3. 読み終えたら「次」と言う（または下の「次」を押す）
  4. 最後まで行ったら、まとめて保存する

撮った動画はこのスマホの中だけに残り、このページからはどこにも送りません。ただし声の「次」をオンにすると、聞き取りのために音声がブラウザの会社（Apple・Google など）の仕組みで処理されることがあります。気になる時はオフにして画面の「次」を押してください。原稿は URL の「#」より後ろに入っていてサーバーには届きませんが、URL を知っている人は原稿を見られます。
