# 撮影プロンプター（無料・スマホだけ）

AI（Claude Code／Codex）が原稿を作り、スマホのインカメラで原稿を見ながら撮れる URL を渡します。
原稿が出る →（ナレーションが問いを読む）→ ピッで撮影開始 →「次」で次の場面。

## 始め方（3つ）
1. 右上の **Use this template** → **Private** で自分のリポを作る
2. Claude アプリの **Code** タブ（または ChatGPT の **Codex**）で、作ったリポを選ぶ
3. 「AGENTS.md を読んで、始めて」と送る

## 中身
- `prompter/index.html` プロンプター本体（1ファイル・撮った動画はスマホの中だけ）
- `tools/url.py` 原稿から URL を作る（原稿は URL の # より後ろ＝サーバーに届かない）
- 置き場所：https://sugukuru.yoseca.com/prompter/

## ご注意
- 声の「次」は、ブラウザの音声認識が使える機種だけ（使えない時は画面の「次」を押す）。
- ナレーションはスマホの読み上げ機能（無料）。声は機種で変わります。
- 結果は保証しません。Claude Code は Claude の有料プラン（Pro 以上）、Codex は Codex が使える ChatGPT のプランが必要です。
